# Luna AI TMA

Frontend-only Telegram Mini App for AI companions (TikTok-style feed).

## Stack

- React + Vite + TypeScript
- Tailwind CSS
- @twa-dev/sdk (Telegram WebApp)
- Zustand + localStorage

## Run

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Notes

- Mock data only (no real backend/payments)
- EN default, RU/EN switcher in Settings
- Gems in header; energy used in feed logic only
